# Contributing to FlowCascade

Thank you for your interest! Here’s how to help build the system:

## How to Contribute
- Fork this repo and create a feature branch.
- Write or improve documentation in `/docs`
- Create new dual-agents in `/agents`
- Add recursive logic modules in `/src`

## Code Guidelines
- Use Python 3.10+
- Keep logic modular
- Write clear, documented agents
- Submit PRs with purpose and summary

Flow on!
